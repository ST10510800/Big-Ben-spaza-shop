# Big Ben Spaza Shop - Web Development Project (WEDE5020)

## Project Overview
Big Ben Spaza Shop is a functional, 5-page responsive website designed to bring traditional township retail services into a digital environment. The site provides details on daily household groceries, cold beverages, and instant digital utility services (airtime, data bundles, and prepaid electricity top-ups).

## Features
- **5-Page Navigation:** Home, About Us, Services, Bulk Enquiry, and Contact pages.
- **Bulk Order & Enquiry Form:** Includes accessible HTML5 form validation (text, email, tel, date, radio, checkbox, and text area inputs).
- **Responsive Layout:** Clean CSS styling utilizing a custom color palette (Deep Navy `#0A192F` and Amber `#FFB703`).
- **Data Display:** Structured HTML tables for trading hours and bulk order processing timelines.
